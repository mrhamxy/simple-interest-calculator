# Simple Interest Calculator

A simple program that calculates simple interest from the principal amount, the rate of interest and the time period.

## What is simple interest?

Simple interest is interest paid only on the original amount of money, not on any interest already earned.

## Formula

SI = (P * R * T) / 100

- **P** — Principal: the original amount of money
- **R** — Rate: the annual rate of interest, as a percentage
- **T** — Time: the time period, in years
- **SI** — Simple Interest: the interest earned over that period

Total amount = P + SI

## Example

If P = 1000, R = 5 and T = 2:

SI = (1000 * 5 * 2) / 100 = 100

Total amount = 1000 + 100 = 1100

## How it works

1. The user enters the principal, the rate and the time.
2. The program applies the formula above.
3. The program displays the simple interest and the total amount.
